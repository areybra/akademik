Cara Menggunakan:

  1. Isikan data di formulir di atas
  2. Copy semua baris data (termasuk baris contoh)
  3. Paste ke Excel atau Google Sheets
  4. Simpan sebagai file CSV (Format: Nama,NIUP,NISN,TgL,tmp,Gender,Kelas,Provinsi,Kabupaten,Kecamatan,Negara,Foto,Status)
  5. Unggah file CSV melalui fitur Impor Data di sistem
